# GOLFOPTIX
## OWN YOUR COURSE

Golf course operations: course maps and irrigation, landscaping and repairs, crew work orders and closure approval, scheduling, Garage and pump equipment, chemical records, budgets and reports.

The public Test Drive uses fictional Juniper Cove records. Real course workspaces require sign-in and server-enforced course membership. Full tools changes presentation, never authorization. Original engineering evidence remains outside the public app repository; the authoritative atlas is separate and is never regenerated by the application.

Phones default to field work through Today, Map, Schedule and More. Computer/tablet navigation retains the complete setup workspaces. The device fallback and global presentation rollback are documented below.

# Calendar weather — November 11, 2026

Maintenance calendar month, week and upcoming-work views now show compact condition symbols plus daytime high / overnight low. Missing dates or missing half-day values remain `? — / —` or individual em dashes; never fabricated temperatures. Celsius/Fahrenheit selection persists in this browser. Printed calendars include the chosen unit. Select a date for Weather details; month cells expose condition/temperature through accessible descriptions as well as their visual badge.

Kings uses the National Weather Service seven-day, twelve-hour period forecast for approximate clubhouse point 28.5115,-81.7200 (Clermont area, not per-hole microclimate or survey geometry). Public course listing: https://www.golfgrandcypress.com/orlando-golf-courses/kings-ridge-golf-club---kings-course . API: https://www.weather.gov/documentation/services-web-api . Use/attribution: https://www.weather.gov/disclaimer . No paid service, account, API key or browser geolocation is required. An authenticated, course-authorized server endpoint fetches only allowlisted NWS sources and exposes no personnel information. Unconfigured tracks return unavailable rather than using Kings weather.

Forecasts refresh on calendar opening, manual Refresh weather, course change and every fifteen minutes while visible. The server caches for fifteen minutes and coalesces concurrent requests within an instance. If upstream refresh fails, cached data can be served for at most two hours, explicitly marked; otherwise placeholders appear. The displayed provider issue time is separate from fetch time. Nighttime lows are grouped with the local date on which the overnight forecast starts. An evening opening can have only tonight's low: today's unavailable high remains blank.

The fictional demo uses seven days of invented, prominently labeled sample weather, not a claimed live forecast for an imaginary course. Forecast detail text from NWS remains the original English source; interface controls have local Spanish translations. Weather never changes work availability, applies products, reschedules jobs or overrides a manager's field weather review. The calendar tour explains symbols, units and missing dates without submitting anything.

A future longer-range/commercial provider can replace the normalized daily feed. Days populate when supplied by that feed; nothing extrapolates beyond the available forecast. This release does not buy or configure such a subscription.

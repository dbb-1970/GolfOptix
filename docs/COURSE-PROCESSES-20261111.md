Application shortcuts filter the process choices. Product choices include previously saved products from the same course/category and seven explicitly marked manufacturer reference examples. All names remain editable; new product names can be entered directly. This is not a chemical inventory, application recommendation, prescription, label-compliance checker, or exhaustive product catalog. No rates, tank mixtures or treatment intervals are prefilled. Completion retains the original process/product snapshot even after future plan edits. The existing calendar shared storage and recovery cover the new process field.

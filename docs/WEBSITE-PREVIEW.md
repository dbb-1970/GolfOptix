# GolfOptix website preview — 28 October 2026

The public front page presents the complete platform vision using the approved GolfOptix artwork and exact GOLFOPTIX / GROUNDED IN TRUTH wording. The interactive implementation is a view-only demonstration: course selection, mock sign-in, a prominent numbered course overview, all 18 hole maps, zoom/pan, water/label controls and printable cards. Kings Ridge Golf Club / Kings Course is the only selection. Ridge Course is deferred.

The owner explicitly authorized publishing the clean r007 Kings Ridge exports in this mock-login demonstration. Original engineering photographs, aerial evidence and the evidence-bearing authoritative master are excluded. Mock login is browser session state, not authentication. It collects no real credentials and must never be reused to protect operational customer data.

The canonical atlas remains ../../masters/KINGS-MASTER.svg. Web derivatives are generated by scripts/prepare-course-preview.py from the approved r007 release. IDs, source geometry and global valves remain intact. The overlay adds clickable hole badges only; all 78 source valves remain in the hole SVGs, with viewport clipping determining visibility. No atlas edits occur in this app.

Preview locally with scripts/preview-server.py. Website deployment uses the existing GitHub main → Netlify workflow, not a new host. The public frontend has no third-party runtime dependencies. Course member authentication, asset editing, durable audits, shared broken/repaired status and highlighted defect printing remain application implementation work. Marketing describes that complete product vision, not implementation proof.

# Garage — November 11, 2026

Maintenance → Garage provides private course equipment inventory. Choose from 382 dated reference entries or enter custom equipment; edit manufacturer/model, specifications, private serial, storage location, documents and nameplate thumbnail. Saving requires an explicit current meter baseline or an explicit unknown/no-meter choice. Browsing the catalog does not create inventory or maintenance history.

Components have independent identities and repair history. Replacement retires the old record. Equipment condition is explicit; a breakdown does not silently change operational condition. Open emergency work blocks new bookings; existing assignments remain visible for reassignment.

Reserve one top-level operating machine per assigned Crew task. Reservations check concurrent tasks, open breakdowns, unavailable components and calendar service; service plans also check existing reservations. Existing shared revision checks reject concurrent conflicting writes. Date and meter plans appear in the maintenance calendar; staff open service work orders manually. Work logs, draft closure and manager approval use the existing Crew workflow.

Crew projections omit private inventory. All Garage records are part of the existing full-course Crew recovery component; isolated recovery verifies the complete record digest and cannot send email. Demo assets/readings are fictional and reset with the existing Test Drive session. No real Kings equipment was created for testing.

Limitations: no machine telemetry, automatic dispatch, stock ledger, validated manufacturer parts fitment or universal service intervals. Manufacturer references are selection evidence, not exact-configuration compatibility. Custom equipment stays private; sharing sanitized custom catalog suggestions still requires a separate reviewed publication workflow.

Validation: model tests cover baselines, booking conflicts in both save orders, availability, approval history and map isolation; recovery test includes a synthetic Garage asset and service plan. Browser checks cover catalog save and reserved task appearance on the calendar.

The 56-step guided demo includes Garage inventory, baselines, availability/components, service, breakdowns and equipment reservation, plus area-wide landscaping. An Ease of use stop explains slider previews and exact entry. Landscape size/rotation and station icon size use visual controls without bypassing save confirmation.

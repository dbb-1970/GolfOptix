# Current GolfOptix documentation

The in-app Support Library and Course Library are the current user-facing instructions. Open Learning after sign-in, or use the public [demo Learning library](https://golfoptix.com/test-drive/learn/). The public superintendent tour is launched from the demo; it previews full tools and returns phone users to their prior field view when ended.

## Current references

- [Documentation review — 18 November](DOCUMENTATION-REVIEW-20261118.md): all current lessons/classes, illustration updates, contextual help, walkthrough scope and verification.
- [Phone field-interface release](FIELD-INTERFACE-RELEASE-20261118.md): behavior, limitations and rollback.
- [Mobile workflow classification](MOBILE-WORKFLOW-SCOPE-20261118.md): 142 scenarios and field-versus-office boundaries.
- [Screen-by-screen owner audit](UI-AUDIT-PROGRESS.md): owner feedback and approval remain separate from documentation review.

User-facing content lives in public/assets/learning-catalog.json, with English and Spanish text and device notes. Illustrations are generated by scripts/build-learning-illustrations.py; examples are explicitly simplified, not exact live screens or engineering evidence. Walkthrough steps live in public/assets/demo-tour-model.js; their local Spanish translations are in es-ui.json. Context help is in map-help.js and calendar-app.js.

Taught course lesson snapshots and customer-authored lessons are operational records. Updating the generic catalog does not rewrite those snapshots. Reprinting a historical taught version must preserve its historical content.

## Historical material

Older release/research documents are retained for provenance. Mock-login-only, browser-local-only and earlier phone-navigation directions in dated documents are historical, not current operating instructions. Do not follow them to change authentication, course storage or atlas geometry. The app and server permissions remain authoritative.

## Mobile training and remaining audit

The separate mobile-only walkthrough is now in the demo menu. It remains in phone field view and ends in the illustrated mobile field course in Learning → Course Library. Desktop users can open /test-drive/mobile/ for a fixed phone preview. See MOBILE-TRAINING-20261118.md. Actual iPhone field acceptance and remaining screen audit items are also not certified by this review.

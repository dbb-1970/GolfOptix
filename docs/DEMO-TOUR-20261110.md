# Superintendent demo walkthrough — November 10, 2026

A 24-step guided tour runs only on the four public Test Drive routes: map, Maintenance, maintenance calendar and Crew. Pine-and-gold flyouts point to the actual control with a spotlight and connecting arrow. Every flyout has NEXT and END INSTRUCTION, with BACK after the first step. Escape ends the guide. NEXT on the final step also ends it.

The guide starts once per tab on a first demo visit, after the workspace loads. A Superintendent tour button on each demo page restarts the full guide from the map. Visiting a different demo section directly begins that chapter instead of bouncing back to an unrelated page. Only validated, non-sensitive tour progress is saved in sessionStorage, with a one-hour expiry. Ending suppresses automatic reopening on refresh. No course edits, worker records, credentials or personnel data are stored by the tour.

Steps cover map pan/zoom/fit, holes, all four layer choices, feature details, repair notes, editable coverage radius, landscape addition, printing, the Maintenance hub, creating a watering/application plan, location and recurrence, calendar views, Crew views, worker invitation/profile fields and access levels, assignments and instructions, schedule copying, tickets and returning to the map. The tour opens example panels and empty forms but never presses a Save, Print or email button. A tour-owned form uses the existing Close handler when advancing to another form; unsaved work retains its existing discard confirmation. Ending the tour leaves an open form available to the user.

Phone steps open the relevant Holes/Layers/More drawer or edit toolbar. Flyouts stay above bottom map navigation; content can scroll on short screens. Native modal forms host their own flyout so its controls remain usable in the browser’s top layer. Keyboard focus, Escape, live instructions, reduced motion and print suppression are supported. Tour navigation follows the demo’s existing page-level reset behavior; it does not preserve practice edits across pages. This is explained before moving between workspaces.

Validation: all 24 steps traversed on desktop and at 390 × 844 phone size with no missing targets, including the native calendar and Crew forms. End/restart and suppression after reload checked. Automated tests cover progress validation/expiry, constrained flyout placement and demo-only navigation. Existing application checks remain in the build. No live worker/account or email was created or sent by this work.

Rollback baseline: `8d2cce634ad2f0640c9321c7e46ad2f2e760ee55`. Reverting this release removes the demo script/style links and tour files. Customer pages, stored records, map assets, authentication, DNS and email settings are unchanged.
